# Анализ банковских операций

Учебный Python-проект для анализа банковских транзакций из Excel-файла. Приложение формирует сводку по картам, показывает крупнейшие операции, рассчитывает кешбэк и расходы по категориям, выполняет поиск по транзакциям, а также получает курсы валют и стоимость акций через внешние API.

## Возможности

- приветствие пользователя в зависимости от времени суток;
- подсчёт расходов и кешбэка по каждой карте;
- получение пяти крупнейших транзакций за выбранный период;
- расчёт выгодных категорий кешбэка за месяц;
- поиск операций по описанию или категории;
- поиск переводов по номеру мобильного телефона;
- отчёт о расходах по категории за последние три месяца;
- получение актуальных курсов валют и котировок акций;
- сохранение результатов в JSON и ведение логов.

## Технологии

- Python 3.14+
- Poetry
- pandas и openpyxl
- requests
- python-dotenv
- pytest и pytest-cov
- Black, isort, Flake8 и mypy

## Установка

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <URL-репозитория>
   cd course_work_1
   ```

2. Установите [Poetry](https://python-poetry.org/docs/#installation), если он ещё не установлен.

3. Установите зависимости проекта:

   ```bash
   poetry install
   ```

4. Создайте файл `.env` в корне проекта и добавьте API-ключи:

   ```env
   CURRENCY_API=ваш_ключ_fxratesapi
   STOCK_API=ваш_ключ_twelvedata
   ```

   Ключи используются для запросов к [FXRatesAPI](https://fxratesapi.com/) и [Twelve Data](https://twelvedata.com/). Без них функции получения курсов валют и котировок не смогут вернуть актуальные данные.

## Настройка

В файле `user_settings.json` задаются интересующие пользователя валюты и акции:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

Исходные транзакции должны находиться в файле `data/operations.xlsx` и соответствовать структуре, используемой функциями проекта.

## Запуск

Запустите приложение из корня проекта:

```bash
poetry run python main.py
```

Демонстрационные параметры запуска заданы в блоке `if __name__ == "__main__"` файла `main.py`. Их можно изменить перед запуском:

- дата — в формате `ДД.ММ.ГГГГ`;
- поисковая строка — часть описания или категории операции;
- категория — название категории для отчёта.

После выполнения программа обновляет:

- `data/main.json` — сводные данные главной страницы;
- `data/report.json` — отчёт по выбранной категории;
- `logs/*.log` — журналы работы модулей.

## Тестирование

Запуск всех тестов:

```bash
poetry run pytest
```

Запуск тестов с отчётом о покрытии:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

## Проверка качества кода

```bash
poetry run black --check .
poetry run isort --check-only .
poetry run flake8 src tests main.py
poetry run mypy src main.py
```

